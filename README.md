# AutoStreamPopout

Vencord plugin that automatically opens streams you watch in Discord’s native pop-out window. Reuses the existing call window and leaves your own stream alone.

## Install

Requires a [Vencord source build](https://docs.vencord.dev/installing/). From the Vencord directory:

```sh
git clone git@github.com:komparator147477/auto-stream-popout.git src/userplugins/autoStreamPopout
pnpm build
pnpm inject
```

Fully restart Discord and enable **Settings → Vencord → Plugins → AutoStreamPopout**.
